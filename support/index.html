Need help transferring from iPhone to PC?

  1. Connect iPhone and computer to the same Wi‑Fi.
  2. Select files in DeskShuttle → Start transfer.
  3. Open the shown URL in your computer browser.
  4. Enter the 6-digit code and approve on the iPhone.
  5. Keep DeskShuttle open during large transfers (iOS pauses background apps).
